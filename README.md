⚡ NeonFit Ultra — Gym & Fitness Landing Page

A high-energy, modern, and fully responsive gym and fitness landing page built using HTML5, Tailwind CSS, Custom CSS, and Vanilla JavaScript. NeonFit Ultra features a bold dark-neon aesthetic, interactive UI elements, smooth animations, and an engaging user experience.

"NeonFit Banner" (https://images.unsplash.com/photo-1534438327276-14e5300c3a48?q=80&w=1600&auto=format&fit=crop)

✨ Features

- ⚡ Interactive Cursor Effects — Custom mouse trail and glowing effects.
- 🌌 Animated Background — Dynamic neon gradients and animated background elements.
- 🏋️ Hero Section — Eye-catching fitness visuals with floating animations.
- ♾️ Infinite Marquee — Scrolling fitness slogans, statistics, and testimonials.
- 📅 Class Schedule — Interactive filters for Yoga, HIIT, Strength, CrossFit, and Cycling.
- 💰 Pricing Calculator — Monthly and annual membership pricing with discount calculations.
- ❓ FAQ Accordion — Expandable frequently asked questions.
- 📱 Responsive Design — Optimized for desktop, tablet, and mobile screens.
- 🎨 Modern UI/UX — Dark theme, neon accents, typography, and visual effects.
- 🎬 Smooth Animations — Animated transitions and scroll-based reveals.

🚀 Getting Started

Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- Internet connection for CDN-hosted libraries and images

Installation

1. Clone the repository:
   
   git clone "url"

2. Open the project folder in Visual Studio Code.

3. Open "index.html" in your browser, or use the Live Server extension.

No build tools or package installation are required for the standalone HTML version.
